TI-84 Plus CE-emulator från https://github.com/hunterchen7/ti84ce (MIT-licens, se LICENSE.txt),
byggd från commit eb90c33 med en egen ingång (matte.html) för Matte-appen.
Bygg om med: npm run build:ti84

Ingen ROM eller TI-mjukvara följer med. Emulatorn kör den ROM-fil du själv väljer
från din egen räknare; den sparas bara lokalt i webbläsaren.
